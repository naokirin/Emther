# 個人・機密情報チェック

作成日: 2026-09-13  
性質: **実装方針メモ**（v1 確定）  
画面: `/mask-check`（相談グループのサブタブ）  
API: `POST /api/mask-check`

---

## 0. 目的

大きめのテキストや自分で書いていないテキストを、Journal／相談／Observation Dump などに投入する前に、次を**ローカルだけで**事前確認できるようにする。

- 登録済み人名がどう `PERSON_n` に置換されるか
- 個人情報・機密情報っぽい箇所の候補リスト

安心のためのオプトイン検証ツールであり、日常の短い入力を止めない。

---

## 1. 非目的（v1）

- この画面からの保存・Journal／Issue／相談の開始
- テキストの自動修正・マスク編集 UI
- 「確認済み」フラグの永続化
- 他画面への強制モーダル組み込み
- 人名以外の機微情報の自動除去・マスク

---

## 2. 決定事項

| # | 決定 | 内容 |
|---|---|---|
| 1 | ラベル | **個人・機密情報チェック**（「送信前」と付けない＝ここから送れないことを明示） |
| 2 | 副作用 | **ゼロ**（人名の新規登録なし／ack なし／ディスク永続なし／外部 CLI・クラウド送信なし） |
| 3 | 実行 | **二段**。第1段（即時）マスク＋ルール検知 → 第2段は**常時**ローカル AI（追加ボタンなし） |
| 4 | 投入 | しない。マスク後テキストのコピーのみ可 |
| 5 | 精度 | 保証しない。UI で「推測・漏れ・誤検知あり」と明示 |

---

## 3. 処理

### 第1段 `phase: "quick"`

- `previewNameMask`（登録済み人名のみ）
- ルール検知: `email` / `phone` / `url_secret` / `api_key_like`

### 第2段 `phase: "ai"`（クライアントが quick 成功後に自動呼び出し）

- ローカル SLM（`runLocalChat`）で機微候補: `health` / `compensation` / `credential_mention` / `customer_or_contract` / `other_sensitive`
- 未登録の人名っぽい語句（登録はしない）
- 長文は先頭 `MASK_CHECK_AI_EXCERPT_CHARS` 文字のみ AI に渡す
